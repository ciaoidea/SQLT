SQL Tensor

Persistent memory. Semantic retrieval. Numerical prediction.

SQL Tensor stores structured events, original evidence and vectors in MariaDB. An MCP-connected language model interprets requests and writes answers; local code stores, retrieves and processes the memory.

Biologically inspired: immediate experience storage, associative retrieval and online learning from observed outcomes.

Structure

Language model
      |
     MCP
      |
Memory and tensor operations (NumPy)
      |
   MariaDB
      +-- Events, roles and original evidence
      +-- Semantic vectors <-- Local encoder (ONNX)
      +-- Learned operators and observed outcomes

How it works

SQL filters retrieve exact matches. A frozen local encoder produces embeddings for semantic search. Small tensor operators learn from explicitly observed outcomes and return predictions. Retrieved evidence supports answers; predictions remain hypotheses.
